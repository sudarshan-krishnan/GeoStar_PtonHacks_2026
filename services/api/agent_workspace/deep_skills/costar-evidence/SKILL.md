# CoStar evidence

1. Start with `get_property_intelligence` (building, valuation, occupancy, redevelopment, community, market sections),
   then `identify_data_gaps` for what no dataset can tell you.
2. Value: `find_sales_comps`; acquisition and returns: `underwrite_acquisition`; an existing building: `evaluate_conversion`;
   neighbours: `find_adjacent_properties`; homes and noise: `analyze_residential_impact`; market: `analyze_submarket`.
3. Every result carries a label (Sourced, Estimated, Screening, Unknown) and a source count. Quote the label.
4. "Unknown" stays unknown: no tenant record is not vacancy, no comps is not a value of zero.
5. Unless the deployment allows it, CoStar names, addresses, prices, rents and coordinates are withheld from you. The user
   sees the full record next to your answer. Refer to the evidence id; never guess a withheld value.
